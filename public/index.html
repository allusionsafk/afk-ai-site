Local AI on Windows. Less plumbing.

AFK AI is a native Windows app that checks your PC, sets up a local model and the services around it, and opens chat on this machine. When something is in the way, it tells you the one next step.

What the app does for you

AFK AI owns the parts that usually stop people: the prerequisites, the runtime, the start order and the recovery. You see one state and one next action.

  1. It checks before it downloads

    Windows, virtualization, WSL, Docker and your hardware are checked first. If something is missing, Setup names it and offers the one action that fixes it, then checks again. Your answers and progress are kept.

  2. It starts everything in order

    Home starts the model runtime and Docker Desktop, then the chat services. It shows that it is starting while that happens, and reports ready only after chat has actually answered.

  3. It refuses what it cannot prove

    AFK AI only stops or changes containers it can prove it created. Anything else is left alone, and the reason is written in plain words.

Before you install

This is a Beta. These are the edges you are most likely to meet.

Windows
Windows 11, 64-bit
Graphics
An NVIDIA GPU is recommended. Without one it runs on the processor, slowly.
Space
About 40 GB free. The first setup downloads several gigabytes.
Virtualization
Required, for Docker Desktop and WSL.
  • Setup can pause for Windows. A restart or Docker Desktop's first launch may still be needed partway through.
  • Chat opens in your browser. The app checks the local services, then opens Open WebUI.
  • If setup stops, keep the exact message. The diagnostics report is what support needs.

Where your data goes

Local-first is a boundary, not a promise that nothing ever touches the internet.

Stays on this PC

The model, your prompts and answers, and the chat database. Setup does not finish until it has verified a Windows Firewall rule that blocks AFK AI's ports on your Wi-Fi and Ethernet adapters.

Uses the internet

Setup, model downloads, updates, and web search when you turn it on.

Being worked on
