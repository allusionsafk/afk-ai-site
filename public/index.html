Beta limits

The rough edges are part of the brief.

  • 01

    Prerequisites can interrupt setup.

    Virtualization, WSL, Docker first-launch, and restart blockers may appear later than intended.

  • 02

    The first run is substantial.

    Setup downloads several gigabytes and needs about 40 GB of free space.

  • 03

    Control Center is separate.

    The current installer does not promise to launch the local dashboard automatically when setup finishes.

AFK / 002Product proof without simulated UI

AFK / 003Network boundary

Local-first is a boundary, not a magic word.

Model inference and the local chat database stay on the machine. AFK AI has no cloud account or subscription. Internet access still has specific jobs.

On your PC

Browser→Open WebUI→Ollama

User-facing services use loopback. Ollama uses a Docker-reachable Windows host bind with a Windows Firewall guardrail for physical network adapters.

Crosses the boundary when used

Setup · model downloads · updates · optional web search

TRUTH / CNot a shipping promise

Development direction

Make setup explain itself sooner.

  1. Earlier prerequisite detection

    Surface virtualization, WSL, Docker, and restart requirements before long-running work begins.

  2. Clearer hardware guidance

    Make model choices easier to understand without claiming universal or optimal tuning.

  3. Better recovery context

    Keep errors and diagnostic evidence actionable while protecting user content.
